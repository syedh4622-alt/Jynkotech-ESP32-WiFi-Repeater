# Contributing

Thanks for improving the Jynkotech ESP32 Wi-Fi Repeater.

1. Open an issue describing the bug or improvement, and mention your board and Arduino-ESP32 version.
2. Fork the project and create a feature branch.
3. Keep the firmware compatible with the built-in ESP32 Arduino core libraries wherever possible.
4. Describe how the change was tested. Mark untested features clearly.
5. Submit a pull request; never include private Wi-Fi passwords or device-flash dumps.
